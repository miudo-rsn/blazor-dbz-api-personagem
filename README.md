# BlazorDbzPersonagem

Aplicação em Blazor (.NET 8) que consome a API do Dragon Ball
(https://dragonball-api.com/api/characters/{id}) e mostra o nome,
o planeta de origem e as transformações do personagem.

## Como rodar

```
dotnet run
```

Depois abra http://localhost:5080, digite um id (ex.: 1) e clique em Buscar.
